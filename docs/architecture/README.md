# Architecture

This directory contains architecture documentation for the LRA Software platform.

Architecture documentation describes the current intended structure of the platform, including system boundaries, component relationships, deployment architecture, and relevant diagrams.

Unlike Architecture Decision Records, which preserve the history and rationale of significant decisions, documents in this directory describe the architecture as it currently exists.

Future documentation may include:

- system context;
- container and component views;
- repository boundaries;
- deployment architecture;
- integration flows;
- architecture diagrams.

Architecture documentation should evolve as the platform changes while relevant historical decisions remain preserved in `docs/adr/`.
